# Upstream ownership and distribution

Scanner is copyright (C) 2012 Steffen Gerlach. This project is an independent,
unofficial patch and does not claim ownership of Scanner or author endorsement.

The supplied Scanner.en.txt, section 7 (Terms of Use), states:

> Everyone is permitted to distribute the package in any way without my explicit agreement.

It also identifies the software as freeware. These terms explicitly allow
redistribution of the package; they do not explicitly address modified binaries.
We therefore do not treat them as a clear grant to publish the patched EXE.
This is a conservative project distribution decision, not a legal opinion.

The original author page is http://www.steffengerlach.de/freeware/.
It could not be retrieved during the 2026-09-11 check; the bundled terms are
the direct evidence used here, not a claim about newly verified online terms.

Only the independent patch tooling, tests, and documentation belong in this
repository. Neither the original nor patched executable, original resources,
language files, full original manuals, nor private logs are included. The README
includes one screenshot supplied by the maintainer for publication, with no
personal file paths visible. Users must supply their own supported executable.
The original Scanner interface shown in that screenshot remains attributable
to Steffen Gerlach and is not relicensed under this project's MIT license.

The project's MIT license applies only to its independently authored material.
It does not relicense Scanner or grant rights in the upstream program. Obtain
explicit permission from the rights holder before changing this project's
policy to distribute a modified Scanner executable.
